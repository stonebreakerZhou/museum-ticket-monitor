# 国博余票监控

众所周知，国家博物馆一票难求，并且每天下午17:00放票之后需要不断刷新并监控余票长达近40min，正因如此，本仓库推出一个建议实现的python脚本，用于本地运行，应用于查询国家博物馆基本陈列 / 庞贝特展的余票状态，发现有可约日期就微信 / 邮件进行通知。

**只查不抢**。为避免违反法规，本脚本不会进行抢票，中国公民一概只能自己去微信小程序手动下单。

---

## ⚠️ 风险提示（必读）

本工具会向国博服务器（`pcticket.chnmuseum.cn`）周期性发送 HTTP 请求，**频率过高可能触发国博风控**。

国博自 2024 年暑期以来已封禁 **165.7 万个高频访问 IP**、**42.5 万个风险账号**，风控维度包括：

- 访问频次风险
- 下单行为风险
- 履约行为风险
- 证件绑定风险

本脚本**没有下单行为**，但持续高频轮询仍可能被判定为"高频 IP"进入风控名单。**从国博视角，你的访问模式和黄牛脚本无法区分**。

### 强烈建议

- **日常**：间隔 ≥ 60 秒，一天查询总时长控制在 1 小时以内
- **放票前后 16:55-17:10**：可用 5-15 秒高频轮询
- **不在 17:00-17:08 持续高频**：该时段已有 geetest 验证码，再叠加高频极易触发限流
- **如果不幸被封**：重启路由器可换公网 IP；4G 热点通常可绕过

详细数据来源：[国博官网公告](https://www.chnmuseum.cn/zx/gbxw/202408/t20240823_269985.shtml)、[新华网](https://english.news.cn/20240824/01eb8e7b9f8f4296a613a3b5a5a0c0f1/c.html)。

## 不是什么

- 不是抢票工具
- 不登录、不绕过验证码、不模拟点击
- 不存个人信息（脚本不收集你的身份证、手机号等）
- 不向国博服务器发伪造请求

只用国博官方公开、不需登录的余票查询接口，也就是国家博物馆英文网站（面向非中国公民购票），普通浏览器请求就能拿到。

## 快速开始

需要 Python 3.10+。

```bash
git clone https://github.com/stonebreakerZhou/museum-ticket-monitor.git
cd museum-ticket-monitor
pip install -r requirements.txt
cp config.ini.example config.ini
python main.py
```

首次运行会提示：

```
请选择监控展厅：
  1. 基本陈列（免费常设展）
  2. 庞贝特展（付费特展）
请输入选项 [1]: 

请输入重点关注的日期（YYYY-MM-DD，逗号分隔）
默认 （空=所有可约日期），直接回车: 2026-08-25

请选择轮询间隔：
  1. 5 秒（极限频率，可能被限流）
  ...
  7. 5 分钟（推荐）
  ...
请输入选项 [7]: 
```

`Ctrl+C` 退出。日志写到 `logs/monitor.log`，另开窗口实时查看：

```powershell
Get-Content logs/monitor.log -Wait
```

## 详细配置

`config.ini` 各字段：

| 节 | 字段 | 说明 |
|---|---|---|
| `[monitor]` | `target_dates` | 默认监控日期。留空 = 所有可约日期；填 `2026-08-23,2026-08-30` 只监控指定日期。运行时仍可手动输入覆盖。 |
| `[museum]` | `api_channel` | 国博接口 channel 参数，一般 `pc` 即可 |
| `[notifier]` | `type` | 通知方式：`off` / `serverchan` / `email` / `both` |
| `[notifier]` | `serverchan_sendkey` | Server酱 SendKey。申请：<https://sct.ftqq.com/> |
| `[notifier]` | `smtp_host` / `smtp_port` / `smtp_user` / `smtp_pass` | SMTP 服务器。`smtp_pass` 是授权码，不是登录密码。 |
| `[notifier]` | `mail_to` | 收件邮箱 |

**通知内容示例**（有可约日期时）：

```
🎉 国博有余票！

可约日期：
  ✅ 2026-08-25（基本陈列）

预约入口：https://pcticket.chnmuseum.cn/museum-en/#/personal/index
```

## 调度策略

### 放票规则

国博每天 **17:00** 按比例放出**未来 7 天内**每个参观日的预约量（即第 8 天的票在前 7 天的 17:00 放出），周一不可约（闭馆）。

### 推荐频率

| 时段 | 推荐间隔 | 说明 |
|---|---|---|
| 16:55-17:10 | 5-15 秒 | 放票前后高频轮询 |
| 其他时段 | 60-300 秒 | 低频监控即可 |

### 频率档位

| 档位 | 间隔 | 请求频率 | 风险 |
|---|---|---|---|
| 1 | 5 秒 | 720 次/小时 | 极高，**可能被风控** |
| 2 | 10 秒 | 360 次/小时 | 高，限 17:00 前使用 |
| 3 | 15 秒 | 240 次/小时 | 中，限 17:00 前使用 |
| 4 | 30 秒 | 120 次/小时 | 中，可短时使用 |
| 5 | 60 秒 | 60 次/小时 | 低 |
| 6 | 100 秒 | 36 次/小时 | 低 |
| 7 | 300 秒 | 12 次/小时 | 很低，**推荐日常** |
| 8 | 600 秒 | 6 次/小时 | 很低 |

## 相关知识

### 用到的接口

`https://pcticket.chnmuseum.cn/prod-api/pool/ingore/getCalendar`

参数：`saleMode=1, hallType=91, openPerson=1, channel=pc`

无需登录、公开可访问。返回未来 14 天每日状态，以及每个展厅的余票池。

> 注：另一个公开接口 `/basesetting/HallSetting/ingore/gainAllSystemConfig` 也返回日历数据，但 `status` 字段粒度不够——它对所有未来可预约日期都返回 `status=3`，**不能区分是否真的有票**。本脚本使用 `getCalendar` 接口，从 `hallTicketPoolVOS` 字段里读取真实票数。

### status 字段含义（来自接口实测）

| 值 | 含义 | 可约？ |
|---|---|---|
| `-1` | 不可约（闭馆 / 过期 / 未开放） | ❌ |
| `0` | 已满 / 售罄 | ❌ |
| `1` | 可预约（今日） | ✅ 需 `ticketPool > 0` |
| `3` | 可预约（未来日期） | ✅ 需 `ticketPool > 0` |
| `4` | 受限 / 维护（看 `ruleContent` 字段原因） | ❌ |

**可约判定**：`status in (1, 3) AND ticketPool > 0`。两个条件必须同时满足。

### hallType 字段

| 值 | 含义 |
|---|---|
| `4` | 基本陈列（免费） |
| `5` | 庞贝特展等付费特展 |

`hallTicketPoolVOS` 数组里每个元素带 `hallId` 字段，按 `hallId` 区分：

| hallId | 展厅 |
|---|---|
| `1` | 基本陈列（免费） |
| `750` | 叩问永恒——庞贝的探索与发掘（120/60 元） |

### 国博反爬措施

- **封禁高频 IP**：动态识别持续高频请求的 IP，加入临时 / 永久黑名单
- **验证码**：17:00-17:08 强制 geetest 滑块 / 点选验证；其他时段低频访问不弹
- **170/171 虚拟号段**：不允许预约
- **同证件号限流**：每周 1 次、每月 4 次、每天 1 次
- **未履约惩罚**：累积 3 次未履约限制 30 日

### 预约规则

| 规则 | 限制 |
|---|---|
| 每个账号 | 每周最多预约 1 次，每次最多 5 人 |
| 同一证件号 | 每月最多 4 次，每天仅 1 次 |
| 常用联系人 | 至多 10 个，添加后 30 天不可变更 |
| 未履约 | 累积 3 次限制预约 30 日 |
| 退票 | 仍计入预约次数 |
| 注销账号 | 30 日内无法重新注册 |

## 故障排查

**Q: 控制台显示"通知未开启，X 天有余票（仅记录日志）"**
A: 没启用通知。改 `config.ini` 的 `[notifier] type` 为 `serverchan` 或 `email`。

**Q: 所有日期都显示 `[NO]` 但官网实际有票**
A: 国博有时段性放票，每天 17:00 放出第 8 天的票，其他时段票池为空是正常的。

**Q: 提示"API 请求超时"或"SSL 错误"**
A: 检查网络。关闭 VPN / 代理；Windows 手动代理也会干扰：`设置 → 网络 → 代理 → 关闭`。

**Q: 怀疑 IP 被封**
A: 用手机 4G 热点访问 `https://pcticket.chnmuseum.cn/`，能打开就是 WiFi IP 被封了。重启路由器可换公网 IP。
